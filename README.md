# Live Talk character

Live Talk shows DABSy's own character. It looks for, in this order:

1. `dabsy-character.png` or `dabsy-character.webp` in this folder  — **your single character image**. It must have a
   **transparent background** (the picture you sent had a solid black one, so it was not used as-is; a black box would show on the glass card).
2. The existing layered DABSy artwork (body, eyes, bow, halo) from `assets/magic/` — used until (1) exists. Nothing is redrawn.

With a single image the whole character breathes, tilts and pulses with the voice. With the layered artwork the eyes also glow, blink and look around.
